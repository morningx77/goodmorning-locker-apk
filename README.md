# 굿모닝 락커 관리 — 안드로이드 설치 파일

- 최신 버전: **1.0 (3)**
- 받기: [locker.apk](https://github.com/morningx77/goodmorning-locker-apk/raw/main/locker.apk)

## 설치 (태블릿)
1. 위 「locker.apk」를 눌러 받는다.
2. 받은 파일을 연다 → 처음 한 번 「이 출처의 앱 설치 허용」을 켠다.
3. 설치 → 홈 화면 「락커 관리」.

업데이트는 덮어 설치한다(앱을 지우지 않는다 — 지우면 보내지 않은 기록이 사라질 수 있다).
